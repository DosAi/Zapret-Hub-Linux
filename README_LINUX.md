# Установка Zapret Hub Linux

> **Статус совместимости:** полное функциональное тестирование выполняется на
> Kali Linux. Debian/Ubuntu, Fedora, Arch и openSUSE проходят контейнерные
> проверки установщика и считаются экспериментальными. Требуется `systemd`.
> Alpine/OpenRC пока не поддерживается.
>
> **Windows не поддерживается.** В этом форке нет Windows-сборок и
> инструкций по их использованию.

Основное описание форка, благодарности и ссылки на исходные проекты находятся
в [README.md](README.md).

## Автоматическая установка

Zapret Hub Linux не публикуется в APT/DNF/AUR и не устанавливается отдельным
DEB/RPM-пакетом. Используйте исходники с GitHub и корневой `install.sh`.

На новом устройстве вставьте в терминал:

```bash
git clone --depth 1 https://github.com/DosAi/Zapret-Hub-Linux.git && cd Zapret-Hub-Linux && ./install.sh
```

Установщик:

- определяет `apt`, `dnf`, `pacman` или `zypper` и устанавливает зависимости;
- скачивает проверенный по SHA-256 релиз классического
  `zapret-discord-youtube-linux` и подготавливает `nfqws`;
- устанавливает встроенный Zapret 2 в `/opt/zapret2`;
- устанавливает проверенный по SHA-256 официальный Happ 3.3.6, если Happ ещё нет;
- проверяет встроенный TG WS Proxy и его Python-зависимости;
- регистрирует оба Zapret-сервиса, не меняя их текущее состояние и автозапуск;
- добавляет ограниченное PolicyKit-правило для управления только сервисами
  Zapret;
- создаёт `.venv`, собирает Web UI и добавляет ярлык приложения;
- запускает Zapret Hub от имени текущего пользователя.

Telegram Desktop по умолчанию **не устанавливается**. Опциональная установка:

```bash
./install.sh --with-telegram
```

Дополнительные режимы:

```bash
./install.sh --no-launch
./install.sh --dry-run
```

Повторный запуск обновляет управляемую копию приложения. Уже установленный Happ
не обновляется и не перезапускается, чтобы не обрывать текущий VPN. Сторонние установки
классического Zapret и `/opt/zapret2`, а также их конфигурации, сохраняются.

## Выбор и автоматический подбор стратегии

1. Откройте в боковом меню страницу **«Компоненты»**.
2. В карточке **Zapret** или **Zapret 2** выберите режим управления:
   - **«Автоматический»** — приложение проверяет YouTube и Discord и перебирает
     стратегии без ручной настройки;
   - **«Вручную»** — откройте «Настройки» в карточке и выберите стратегию сами.
3. Включите нужный компонент или общую кнопку питания.

Над списком компонентов находится заметная памятка с кнопками быстрого запуска
автоподбора. Переключение между Zapret и Zapret 2 на главном экране само по себе
не запускает проверку стратегий.

## Графическое удаление

Запускайте деинсталлятор **до удаления клонированной папки**:

```bash
cd Zapret-Hub-Linux
./uninstall.sh
```

Он использует тот же Web UI и оформление, что основное приложение. В окне можно:

- сохранить либо удалить пользовательские настройки, логи и сгенерированные данные;
- отдельно выбрать удаление Happ;
- увидеть результат и путь к сохранённой папке исходников.

Установщик также создаёт отдельный пункт **«Удалить Zapret Hub»** в меню
приложений, поэтому терминал для штатного удаления не требуется.

По умолчанию Happ, исходная папка и пользовательские данные сохраняются. Общие
пакеты, установленные через APT/DNF/Pacman/Zypper, не удаляются, потому что они
могут требоваться другим приложениям. Системная часть удаляет только unit-файлы
Zapret Hub и каталоги Zapret/Zapret2 с маркером `.zapret-hub-managed`.

Терминальный резервный режим:

```bash
./uninstall.sh --cli
```

Дополнительные параметры CLI:

```bash
./uninstall.sh --cli --remove-happ
./uninstall.sh --cli --purge-data
./uninstall.sh --dry-run
```

Скрипт автоматически определяет семейство дистрибутива и поддерживает те же
системы, что установщик: Kali/Debian/Ubuntu, Fedora/RHEL, Arch и openSUSE.

## Запуск и диагностика

```bash
~/.local/bin/zapret-hub
```

```bash
.venv/bin/zapret-hub-linux diagnose
.venv/bin/zapret-hub-linux start --dry-run
```
